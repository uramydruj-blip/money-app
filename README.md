# Бухгалтерія — Telegram Mini App

Особистий облік грошей: баланс з «одометром», доходи/витрати за категоріями, статистика надходжень і порівняння періодів, голосовий/текстовий ввід (UA/RU), конвертація ₴/€/$ за курсом НБУ, фони (Аврора/Частинки/Карбон).

* Повністю статичний сайт (HTML/CSS/vanilla JS) — працює 24/7 на GitHub Pages, без сервера.
* Дані: Telegram CloudStorage (по місяцях, з контрольними сумами) + локальний журнал, черга синхронізації, 3 автокопії, експорт/імпорт JSON.
* Прямі посилання: `?startapp=voice` (одразу голос), `?startapp=expense`, `?startapp=income`.

Тести (потрібен Playwright + Chromium): `node tests/parser.test.js`, `node tests/e2e.js`, `node tests/crash.js`.
